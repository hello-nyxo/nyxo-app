# Nyxo

Sleep better. Nyxo shows your nights, heart rate and activity from Apple Health or Health Connect, how your habits line up with your sleep, and the [Nyxo sleep coaching program](https://nyxo.app).

The original app (React Native 0.64, AWS Amplify, Redux) lives on the [`legacy/nyxo-1`](https://github.com/hello-nyxo/nyxo-app/tree/legacy/nyxo-1) branch.

## Run

Requires Node 22, Xcode 26+ and Android Studio (JDK 17).

```bash
npm install
npm run ios        # or: npm run android
```

Health data needs a development build, not Expo Go. In a development build, Today has an Add sample data button: a month of nights, heart rate, steps and habit history for simulators.

## Commands

| Command | |
| --- | --- |
| `npm run ios` / `npm run android` | Build, install and start Metro |
| `npm start` | Metro only |
| `npm run lint` | ESLint |
| `npm run typecheck` | TypeScript |
| `npm test` | Jest |
| `npm run sync-content` | Pull coaching content from Contentful (needs `CONTENTFUL_SPACE_ID`, `CONTENTFUL_ACCESS_TOKEN`) |

## Layout

```
src/app/         Screens (Expo Router): (today)/ is "/", trends/, coaching/
src/health/      night.ts (model), insights.ts (correlations), sample-data.ts, source.<platform>.ts (health stores), use-health.ts
src/coaching/    content.json + images.ts (generated), progress.ts, stats.ts, quiz.ts, recommend.ts
src/lib/days.ts  Local day keys
src/ui/          Shared views: cover, cards, charts, comparison, habits, waffle, ring, sleep clock, stages, prose, parallax
src/global.css   Design tokens for NativeWind (see DESIGN.md)
assets/coaching/ Contentful images (generated)
```

`ios/` and `android/` are generated by `npx expo prebuild`; configure them in `app.json`.
